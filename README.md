# 初九框架发行仓库

这里发布初九框架（ChuJiu Framework）的 WordPress 插件安装包和版本说明。

开发仓库保持私有。本仓库不存放开发提交历史、测试、打包工具或项目自定义代码。插件 ZIP 包含运行所需的 PHP、CSS 和 JavaScript 文件。

## 安装与更新

1. 打开 Releases，下载对应版本的 `chujiu-framework.zip`。
2. 在 WordPress 后台选择“插件 → 安装插件 → 上传插件”，安装并启用。
3. 后续可以点击“立即更新”，或在插件列表中选择“启用自动更新”。

项目自定义代码和模板由各网站主题维护，请勿放进框架插件目录。

稳定版本标签采用 `v版本号`，例如 `v1.0.6323`。请下载上传的插件 ZIP 附件，GitHub 自动生成的 Source code 压缩包不是插件安装包。
